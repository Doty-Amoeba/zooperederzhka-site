# Зоопередержка — сайт

Готовый статический сайт. Открывается двойным кликом, без сервера и сборки.

## Как открыть

Дважды кликни по файлу `index.html` — сайт откроется в браузере.

## Как поменять тексты и цены

Открой файл `site-data.js` в любом текстовом редакторе (Блокнот подойдёт).
Там лежат все тексты, цены, контакты, цвета и координаты карты.
После правки сохрани файл и обнови страницу в браузере (F5).

Файлы `index.html`, `styles.css` и `app.js` менять не нужно.

## Контакты для правок

Если нужна помощь с сайтом — свяжись с тем, кто передал тебе эту папку.
